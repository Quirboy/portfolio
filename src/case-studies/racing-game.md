## Overview

This was my first time making a racing game. I built the project in a short period and used it to learn how the driving and race systems fit together. The prototype still has bugs and areas I would like to improve.

## Game features

- Race counter
- Ghost mode
- Leaderboard
- Lap-time tracking
- AI opponents

## Level design and tools

I created the level design myself. The remaining assets were sourced from itch.io and imported into Unity.

## What I learned

The project helped me practise Unity development, Unity UI, simple AI behavior, and the Unity Input System while building a racing-game loop.
